# Revisão ESPRO

Projeto de apresentação/estudo sobre Inteligência Emocional, desenvolvido em HTML, CSS e JavaScript como uma página interativa para revisão dos 5 componentes de Daniel Goleman.

## Preview

![Preview do projeto](./Screenshot%20from%202026-09-29%2013-41-37.png)

## Sobre o projeto

A página apresenta:

- uma apresentação visual dos cinco pilares da inteligência emocional;
- cartões interativos para revisar cada conceito;
- uma explicação em linguagem acessível para estudo e apresentação;
- um layout visual com tema escuro e elementos inspirados em xadrez.

## Como abrir

Basta abrir o arquivo `revisao.html` em qualquer navegador.

Se preferir rodar em um servidor local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000/revisao.html`.
